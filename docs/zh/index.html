2   const map = new Map<number, number>();
3
4   for (let i = 0; i < nums.length; i++) {
5     const complement = target - nums[i];

可以解释一下这个解法的时间复杂度吗？

这个解法在遍历时使用哈希表保存数字。

  • 时间复杂度：O(n)
    只需遍历数组一次。
  • 空间复杂度：O(n)
    最多保存 n 个元素。
